# 무인민원발급기 — 공통 SDK v0.5.20 설치 및 스마트 길잡이·스크롤 안내 회귀 검증

## 0. 작업 대상 및 기본 원칙

현재 프로젝트는 **무인민원발급기 Replit**입니다.

첨부한 `naebangsik-kiosk-accessibility-sdk-0.5.20.tgz` 파일을 이용해 공통 SDK를 기존 v0.5.19에서 **v0.5.20으로 업데이트**해 주세요.

패키지명: `@naebangsik/kiosk-accessibility-sdk`

이번 SDK의 주요 수정 내용은 다음과 같습니다.

1. 같은 업무 단계에서 숫자 입력·옵션 변경·부수 선택을 해도 스마트 길잡이가 조기 종료되지 않도록 수정
2. 쉬운 말 안내와 하단 스크롤 안내가 안전한 공간에서 함께 표시되도록 수정
3. 하단 스크롤 안내가 스크롤 중 위아래로 이동하지 않도록 안정적인 배치 적용

**SDK-first 원칙을 반드시 지켜 주세요.**

공통 SDK 자체의 결함은 데모커피 프로젝트에서 관리하는 SDK 원본에서 해결해야 합니다.

무인민원발급기에서는 공식 SDK 설치, 공개 API 연결 확인, 실제 업무 단계 검증만 수행하세요.

## 2. 스마트 길잡이 조기 종료 재검증

사용자가 실제 테스트에서 다음 문제를 발견했습니다.

스마트 길잡이가 시작된 상태에서 키패드나 선택지를 누르면 **15초가 지나기 전에 안내가 사라졌습니다.**

문제 발생 화면:

- 숫자 키패드 입력
- 증명서 표시 항목 선택
- 발급 부수 선택

v0.5.20에서는 일반 포인터·키보드 조작으로 스마트 길잡이가 즉시 종료되던 SDK 동작을 수정했습니다.

### 원하는 동작

같은 업무 화면에서 다음을 수행해도 스마트 길잡이가 유지되어야 합니다.

- 숫자 키패드 입력
- 지우기
- 체크박스·선택지 변경
- 발급 부수 증가·감소
- 화면 스크롤
- 같은 화면의 입력 상태 변경

스마트 길잡이는 **표시 시작 후 약 15초가 지나야 자동 종료**되어야 합니다.

단, 다른 업무 화면으로 실제 이동하거나 세션을 종료하면 이전 길잡이는 즉시 정리되어야 합니다.

### 필수 검증

실제 Chromium 브라우저에서 다음을 수행하세요.

1. Development '접근성 체험하기' 실행
2. 해당 화면 진입
3. 약 10초 후 스마트 길잡이 표시 확인
4. 길잡이 표시 중 숫자·선택지·부수 버튼 반복 클릭
5. 안내가 사라지지 않는지 확인
6. 15초 카운트다운 감소 확인
7. 약 15초 뒤 쉬운 말 안내로 복귀하는지 확인

위 세 화면을 각각 개별적으로 검증하세요.

각 화면에서 스마트 길잡이의 실제 표시 시작·종료 시간과 종료 원인을 기록하세요.

## 3. stepId 및 화면 전환 연결 확인

v0.5.20에서는 동일 단계의 일반 조작과 실제 업무 단계 전환을 구분합니다.

무인민원발급기의 호스트 연결이 이 정책과 일치하는지 확인하세요.

### 동일 단계 조작

숫자 입력, 옵션 선택, 부수 변경 같은 값 변경에서는 기존 stepId를 유지해야 합니다.

이런 조작 때문에 notifyScreenChange()를 불필요하게 호출하면 안 됩니다.

### 실제 단계 전환

키패드 → 지문 확인 → 발급 옵션 → 수수료 면제 → 부수 선택 → 신청 내용 확인 → 결제 등 실제 화면이 바뀔 때는 적절한 화면 ID와 stepId를 SDK에 전달하세요.

화면 전환 순서는 현재 구현을 기준으로 확인하고, 없는 화면을 새로 만들지 마세요.

호스트가 같은 화면에서 불필요하게 notifyScreenChange()를 호출한다면 **기존 SDK 공개 API의 정상적인 사용 방식으로만 수정**할 수 있습니다.

SDK 내부 타이머를 직접 조작하는 우회 코드는 만들지 마세요.

## 4. 하단 스크롤 안내 복구 및 검증

사용자가 실제 테스트에서 다음 문제를 발견했습니다.

- 스크롤 가능한 화면인데 하단 스크롤 안내가 거의 나타나지 않음
- 마지막 화면에서만 나타나는 경우가 있음
- 스크롤하면 안내가 위·중간·아래로 불규칙하게 이동

v0.5.20에서는 쉬운 말 안내와 스크롤 힌트가 무조건 서로를 숨기던 조건을 수정했고, 스크롤 힌트의 배치를 뷰포트 기준으로 안정화했습니다.

### 원하는 동작

- 실제로 아래에 더 볼 내용이 있으면 하단 스크롤 안내 표시
- 쉬운 말 안내가 있다고 해서 무조건 숨기지 않음
- 스크롤 안내 위치가 스크롤 중 위아래로 튀지 않음
- 스크롤을 끝까지 내리면 안내를 숨길 수 있음
- 스마트 길잡이·모달과 충돌하면 우선순위에 따라 안전하게 숨김
- 업무 버튼·키패드·QR 도크를 가리지 않음

### 필수 확인

다음 화면을 중심으로 실제 스크롤 여부를 점검하세요.

- 증명서 메뉴 목록
- 숫자 키패드
- 증명서 표시 항목 선택
- 수수료 면제 대상
- 발급 부수 선택
- 신청 내용 확인
- 결제

각 화면마다 다음 값을 확인하세요.

- 실제 스크롤 컨테이너
- scrollHeight
- clientHeight
- scrollTop
- 스크롤 안내 표시 여부
- 스크롤 안내 위치
- 쉬운 말 패널과 충돌 여부
- 스마트 길잡이 표시 중 숨김 여부
- 스크롤 최하단에서 사라지는지 여부

스크롤 안내가 없어야 정상인 화면도 구분해 보고하세요.

## 5. 일반 화면 및 하단 조작 검증

화면 크기:

- 320×844
- 360×667
- 390×844
- 1080×1920

접근성 모드:

- 일반 화면: viewportMode null
- 하단 60%
- 하단 70%
- 하단 80%

특히 **매우 큰 글씨 + 큰 버튼 + 고대비 + 쉬운 말 + 스마트 길잡이 + 하단 60%** 조합을 집중적으로 확인하세요.

다음 동작을 검증합니다.

- 키패드 실제 클릭
- 선택지 변경
- 부수 증감
- 확인·다음 버튼 클릭
- 세로 스크롤
- 안내창 접기·펼치기
- 쉬운 말 이전·다음
- 스마트 길잡이 표시 유지
- 하단 스크롤 안내
- 안내창이 주요 업무 버튼을 가리지 않는지

브라우저 캡처뿐 아니라 실제 클릭 좌표와 hit-test도 확인하세요.

## 6. 쉬운 말·스마트 길잡이 기능 유지

기존 v0.5.19에서 연결한 안내 데이터를 보존하세요.

- 지문 확인
- 증명서 표시 항목
- 수수료 면제
- 발급 부수
- 신청 내용 확인
- 그 외 기존 안내 단계

쉬운 말은 해당 화면 진입 직후 표시되어야 합니다.

스마트 길잡이는 설정된 대기시간이 지난 뒤 표시되어야 합니다.

스마트 길잡이에서는 이전·다음과 페이지 번호가 나타나면 안 됩니다.

스마트 길잡이 종료 후 기존 쉬운 말 페이지와 접힘 상태를 복원하세요.

이번 작업에서는 쉬운 말 안내 문구를 전면 재작성하지 않습니다. 안내 문구 개선은 SDK 안정성 확인 후 별도 작업으로 진행할 예정입니다.

## 7. QR 모달 및 세션 종료 회귀

이전 v0.5.19 설치 과정에서 QR 설정·안내 모달의 확인 버튼이 공통 안내창에 가려지는 문제가 발견됐고, 호스트 공개 API 연결로 수정한 상태입니다.

다음 동작을 유지하세요.

- QR 모달이 열리면 기존 쉬운 말 안내가 모달을 가리지 않음
- 모달 확인 버튼 정상 클릭
- 모달 종료 후 현재 화면 설명 복원
- 스마트 길잡이 타이머가 오래 남아 재등장하지 않음
- 수동 처음으로 돌아가기
- 체험 종료
- 완료 후 15초 자동 복귀
- 시간 연장 시 15초 재설정
- endSession() 후 모든 접근성 설정·타이머 초기화

## 10. 문제 발생 시 원인 구분

여전히 오류가 발생하면 다음을 구분하세요.

A. SDK 내부 문제

- 동일 단계 조작이 여전히 타이머를 종료함
- 스크롤 안내의 좌표 계산 오류
- 안전한 위치가 있는데도 안내가 사라짐

이 경우 이 프로젝트에서 SDK를 수정하지 말고 재현 조건과 진단을 보고하세요.

B. 호스트 연결 문제

- 값 변경 때 불필요하게 notifyScreenChange() 호출
- 잘못된 stepId 전달
- 실제 스크롤 컨테이너 미등록
- 업무 버튼·고정 영역 등록 누락

이 경우 SDK 공개 API 연결만 보완하세요.

호스트 전용 CSS, SDK 내부 패치, 특정 화면의 좌표 하드코딩은 금지합니다.
