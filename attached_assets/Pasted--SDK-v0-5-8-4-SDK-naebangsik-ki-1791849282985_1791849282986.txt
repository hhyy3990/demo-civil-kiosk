# 무인민원발급기 — 공통 SDK v0.5.8 설치 및 스마트 길잡이 4개 화면 연결

현재 프로젝트는 무인민원발급기 시뮬레이션입니다.

기존 SDK는 `@naebangsik/kiosk-accessibility-sdk@0.5.7`입니다.

데모커피 프로젝트에서 개발한 공통 SDK v0.5.8 tarball을 업로드했습니다.

이번 작업의 목적은 **새 SDK의 업무 단계별 스마트 길잡이 기능을 사용해, 기존에 안내가 나타나지 않았던 네 화면을 정상적으로 연결하는 것**입니다.

가장 중요한 원칙은 SDK 우선입니다. 스마트 길잡이의 타이머·팝업·중복 방지 기능을 호스트에 별도로 구현하지 마세요.

## 1. SDK 설치

업로드된 `naebangsik-kiosk-accessibility-sdk-0.5.8.tgz`의 실제 경로와 메타데이터를 확인하세요.

- name: `@naebangsik/kiosk-accessibility-sdk`
- version: `0.5.8`

일치하면 기존 v0.5.7을 교체하고 package.json, lockfile, 실제 node_modules 버전을 검증합니다.

기존 v0.5.7 tarball은 보존합니다.

SDK 소스는 수정하지 않습니다.

## 2. 현재 스마트 길잡이 연결 구조 분석

다음 파일과 실제 API를 확인하세요.

- src/useKioskAccessibility.ts
- src/App.tsx
- 현재 안내 문구 및 행동 ID 등록 코드
- SDK v0.5.8의 GuideState 및 stepId 타입
- notifyScreenChange() 및 setGuideState() 연결 구조

현재 화면 전환과 안내 상태 갱신이 어떤 순서로 이루어지는지 확인합니다.

문제 원인이 단순 안내 누락인지, 단계 ID 누락인지, 타이머 재시작 문제인지 구분한 뒤 수정하세요.

## 3. 반드시 보완할 네 가지 업무 단계

### A. 주민등록번호 키패드 입력

실제 화면의 입력 안내와 다음 버튼을 기준으로 스마트 길잡이를 연결합니다.

예시 안내:

제목: 번호를 입력해 주세요

내용: 화면의 숫자 버튼을 눌러 안내된 정보를 입력한 뒤 다음 단계로 이동해 주세요. 실제 개인정보가 아닌 시뮬레이션용 입력만 사용합니다.

안내에 실제 입력값이나 주민등록번호를 포함하지 마세요.

### B. 증명서 표시 항목 선택

예시 안내:

제목: 표시할 항목을 골라 주세요

내용: 증명서에 표시할 내용을 확인하고 필요한 항목을 선택한 뒤 다음 버튼을 눌러 주세요.

실제 화면에 존재하는 항목·버튼을 기준으로 문구를 조정하세요.

### C. 발급 부수 입력

예시 안내:

제목: 발급할 부수를 정해 주세요

내용: 필요한 증명서의 부수를 선택하고 확인한 뒤 다음 버튼을 눌러 주세요.

부수 숫자를 바꿀 때마다 안내 타이머가 불필요하게 재시작되지 않도록 합니다.

### D. 결제 방법 선택

예시 안내:

제목: 결제 방법을 선택해 주세요

내용: 화면에 표시된 결제 방법 중 하나를 선택한 다음 안내에 따라 진행해 주세요.

현재 시뮬레이션에 실제로 있는 결제 수단만 안내합니다.

## 4. SDK v0.5.8 업무 단계 ID 연결

SDK가 제공하는 선택적 stepId를 사용하세요.

화면 ID와 업무 단계 ID는 구분합니다.

- 화면이 실제로 전환되는 경우: notifyScreenChange()
- 같은 화면 안에서 별도의 안내 단계로 바뀌는 경우: stepId 변경
- 동일 단계에서 값만 변경되는 경우: stepId 유지

ID 예시는 다음과 같습니다.

- certificate.id-input
- certificate.display-options
- certificate.copy-count
- certificate.payment-method

정확한 ID는 현재 코드와 충돌하지 않는 안정적인 값으로 정하세요.

사용자 입력값, 주민등록번호, 결제 정보 등을 ID에 포함하면 안 됩니다.

필요한 경우 기존 안내와 행동 ID는 유지하고 stepId만 추가하세요.

## 5. 타이머 및 안내 표시 정책

다음 조건을 만족해야 합니다.

1. 스마트 길잡이가 활성화된 프로필에서만 표시
2. QR의 10·15·20초 지연 설정 적용
3. 해당 업무 단계 진입 시 새 타이머 시작
4. 같은 단계에서 입력값만 바뀌어도 타이머 유지
5. 다른 업무 단계로 이동하면 기존 타이머 취소
6. 오래된 안내 팝업 및 버튼 강조 제거
7. 같은 안내가 중복 표시되지 않음
8. 화면에 실제 존재하는 버튼만 강조
9. 이전 단계로 돌아가면 적절히 안내 재시작
10. endSession() 후 안내와 타이머 완전 정리

가능하면 QR 프로필을 적용한 상태에서 네 화면 모두 실제 브라우저 대기로 확인하세요.

## 6. 전체 발급 흐름 검증

초기 화면 → 증명서 선택 → 주민등록표 등본 → 가상 숫자 입력 → 지문 확인 → 표시 항목 선택 → 부수 선택 → 결제 방법 → 모의 결제 → 인쇄 → 발급 완료 → 처음 화면 복귀

다음 사항을 확인합니다.

- 스마트 길잡이 네 화면 모두 표시
- 올바른 버튼 강조
- 다른 화면의 이전 안내가 남지 않음
- 값 변경 시 타이머 불필요한 초기화 없음
- 스마트 길잡이가 비활성화되면 표시 안 됨
- 큰 글씨·큰 버튼·고대비 유지
- QR v1/v2/v3 호환
- QR 도크 하단 60·70·80% 동기화 유지
- 스크롤 안내 정상
- 선택적 글씨 자동 보정 유지
- 레이아웃 진단 기존 동작 유지
- 처음화면 복귀 시 세션 초기화

실제 개인정보 대신 테스트용 값만 사용합니다.

## 7. 화면 크기 검증

다음 화면 크기를 확인합니다.

- 320×844
- 360×667
- 390×844
- 1080×1920
- 1440×900
- 1920×1080

특히 360×667에서 스마트 길잡이 팝업이 키패드, 다음 버튼 또는 결제 선택 버튼을 완전히 가리지 않는지 확인합니다.

기존에 사용자가 확인한 큰 글씨·QR 도크 배치는 이번에 임의로 변경하지 않습니다.
