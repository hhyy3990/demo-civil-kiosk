# 무인민원발급기 — 공통 SDK v0.5.29 설치 및 핵심 오류 최종 검증

현재 프로젝트는 **무인민원발급기 Replit**입니다.

데모커피 공통 SDK에서 v0.5.29를 새로 배포했습니다.

이번 작업 목표는 다음 두 오류가 실제 무인민원발급기에서 해결됐는지 확인하는 것입니다.

1. 스크롤 안내가 하단 고정 QR 버튼 또는 footer 버튼을 가리는 오류
2. Smart Guide의 X 버튼을 누른 뒤 같은 업무 단계에서 안내가 다시 나타나는 오류

**기존 호스트 코드와 CSS는 수정하지 마세요. 이번에는 설치 및 검증만 승인합니다.**

## 1. SDK v0.5.29 설치

업로드된 tarball을 먼저 확인하세요.

- 패키지: `@naebangsik/kiosk-accessibility-sdk`
- 버전: `0.5.29`
- 파일: `naebangsik-kiosk-accessibility-sdk-0.5.29.tgz`
- 크기: `90,094 bytes`
- SHA-256: `4fbc3e036c9989b645539501d23ffc2e7951544864ab848fea697151b217a2dd`

크기 또는 해시가 다르면 설치하지 말고 보고하세요.

일치하면:

1. 기존 v0.5.28 tarball 보존
2. v0.5.29 설치
3. package.json·package-lock.json 갱신
4. 필요할 경우 오래된 Vite 최적화 캐시 정리
5. Preview 재시작
6. 설치된 SDK 버전 확인
7. 실제 로드된 SDK JS/CSS가 새 tarball과 일치하는지 확인
8. 타입 검사 및 빌드

실제 설치된 SDK가 v0.5.29인지 확인하고, 이전 v0.5.28 파일이 로드되는 일이 없도록 하세요.

## 2. 최우선 — 파란 QR 버튼과 footer 동시 보호

실제 무인민원발급기 첫 화면에서 검증하세요.

화면 크기: **390×844**

접근성 설정: 기본 모드

실제 DOM:

- 스크롤 영역: `main.stage`
- QR 도크: `.a11y-qr-entry-dock`
- QR 버튼: `.a11y-qr-entry-dock-button`
- footer: `.device-footer`
- 스크롤 안내: SDK 생성 안내 요소

### v0.5.28에서 발생했던 오류

첫 번째 오류:

- QR 버튼 Y=696.50~748.50
- 스크롤 안내 Y=701.61~746
- QR 버튼과 교차 약 9,667px²

두 번째 오류:

- QR 버튼 Y=696.50~748.50
- footer Y=758~844
- 스크롤 안내 Y=787.61~832
- footer와 교차 약 9,667px²

v0.5.29에서는 QR 도크와 footer를 동시에 고려하도록 수정했습니다.

### 실제 성공 기준

다음 요소의 getBoundingClientRect()를 측정하세요.

1. QR 도크
2. QR 버튼
3. footer
4. footer 안의 처음화면·전화면 버튼
5. 스크롤 안내

각 요소와 스크롤 안내의 실제 교차 면적을 계산하세요.

필수 기준:

- QR 도크와 교차 0px²
- QR 버튼과 교차 0px²
- footer와 교차 0px²
- 처음화면·전화면 버튼과 교차 0px²
- 가능하면 QR 도크 위 약 12px 간격
- 스크롤 안내 문구 정상 표시
- QR 버튼 문구 정상 표시
- QR 버튼 클릭 정상
- pointer-events:none
- 스크롤 중 안내 위치 안정적
- 실제 스크롤 끝에서 안내 숨김

SDK fixture의 기존 성공값은 다음과 같습니다.

- 스크롤 안내 Y=629.61~674
- QR 도크 Y=686~758
- footer Y=758~844

이는 참고값입니다. **실제 호스트에서 측정한 값으로 판단하세요.**

### 중요한 구분

일반 스크롤 콘텐츠와 안내가 겹치는 것은 정상입니다.

일반 카드, 입력 영역, 키패드, 스크롤되는 버튼과 안내의 겹침을 오류로 판단하지 마세요.

**고정된 QR 도크와 footer만 보호 대상으로 확인하세요.**

일반 콘텐츠에 추가 여백을 만들거나 스크롤 안내를 숨기는 방식으로 문제를 해결하지 마세요.

## 3. 하단 70%·80% 간단 회귀

360×667 및 390×844에서 확인하세요.

- 명시적 하단 70%
- 명시적 하단 80%
- 쉬운 말 활성화 + viewportMode:null → 자동 하단 80%

각 모드에서 다음만 측정하세요.

- QR 도크·footer와 안내의 교차 면적 0
- 스크롤 끝에서 안내 숨김
- 스크롤 중 위치 점프 없음
- 쉬운 말 이전·다음 버튼 정상
- 기존 쉬운 말 원문 누락·잘림 없음

기존 정상인 모드까지 불필요하게 재설계하거나 수정하지 마세요.

## 4. 최우선 — Smart Guide X 종료 후 재등장 방지

실제 주민등록표 종류 선택 단계에서 검증하세요.

기존 오류:

1. 쉬운 말 안내 2/2 페이지 표시
2. Smart Guide 등장
3. X 버튼 클릭
4. 쉬운 말 2/2 복귀
5. 약 10초 후 같은 Smart Guide 재등장

v0.5.29에서는 X 클릭 시 예약 타이머를 취소하고 같은 단계·같은 안내 내용의 재등장을 방지하도록 수정했습니다.

### 검증 시나리오

1. 쉬운 말과 Smart Guide를 활성화합니다.
2. 주민등록표 종류 선택 화면으로 이동합니다.
3. 쉬운 말 안내를 2페이지로 이동합니다.
4. Smart Guide가 나타날 때까지 기다립니다.
5. 실제 X 버튼을 클릭하거나 터치합니다.
6. Smart Guide가 즉시 닫히는지 확인합니다.
7. **기존 쉬운 말 2/2 페이지로 복귀하는지 확인합니다.**
8. 같은 업무 단계에서 최소 30초간 기다립니다.
9. 해당 Smart Guide가 다시 나타나지 않는지 확인합니다.
10. 다음 업무 단계로 이동하여 새로운 Smart Guide가 정상적으로 예약되는지 확인합니다.

추가로:

- 같은 단계의 UI 재렌더링 후에도 재등장하지 않아야 합니다.
- 같은 stepId·같은 안내 내용의 중복 상태 전달에도 재등장하지 않아야 합니다.
- 다른 단계로 이동한 뒤에는 기존 등장 지연 정책을 유지해야 합니다.
- 새로운 세션에서는 기존 초기화 정책을 유지해야 합니다.

Smart Guide를 전역적으로 비활성화하여 테스트를 통과시키지 마세요.

## 5. 기존 안내 기능 유지

다음 사항을 짧게 확인하세요.

**쉬운 말 안내**

- 접기·펼치기 버튼 없음
- 항상 펼친 상태로 표시
- 이전·다음 페이지 및 페이지 번호 정상
- `1/21` 과분할 오류 재발 없음
- 원문 누락·중복 없음

**Smart Guide**

- 접기·펼치기 버튼 없음
- X 버튼 유지
- X 또는 자동 종료 시 기존 쉬운 말 페이지로 복귀
- 안내 본문 잘림 없음
- 긴 안내 최대 2페이지
- 한 페이지 일반 10초
- 두 페이지 일반 총 15초, 약 7.5초 후 전환
- 느린 안내 총 20초, 두 페이지면 약 10초 후 전환
- 등장 지연 10·15·20초 기존 정책 유지
- 기존 Smart Guide 전용 line-height:1.25 유지

이미 SDK 쪽에서 통과한 검증은 실제 호스트에서 문제가 없으면 불필요하게 반복 실행하지 마세요.

## 6. 핵심 오류가 모두 통과한 경우에만 간단 회귀

두 핵심 오류가 실제 화면에서 해결됐을 경우 다음을 진행하세요.

- 메뉴 18개 유지
- QR 버튼 클릭 및 설정창 열기·닫기
- QR v1~v4 합성 응답 적용
- 주민등록표 등본 선택
- 임의 테스트 숫자 13자리 입력
- 지문 확인 시뮬레이션
- 표시 항목 및 부수 선택
- 가상 결제·인쇄·완료
- 약 15초 후 첫 화면 자동 복귀
- 입력값 및 접근성 설정 초기화
- 세션 종료 후 Smart Guide 재등장 없음

실제 개인정보는 입력하지 마세요.

Production QR 프로필 생성·DB 수정은 하지 마세요. 실제 카메라·음성·Production QR 검증이 불가능하면 미검증으로 명확히 표시하세요.

## 7. 실패 시 처리

다음 중 하나라도 실패하면 해당 사실을 보고하고 코드 수정은 하지 마세요.

- 기본 모드에서 QR 도크 또는 footer와 스크롤 안내 겹침
- Smart Guide X 클릭 후 같은 단계 재등장
- 기존 Easy Language 페이지 복귀 실패
- 쉬운 말 과분할 재발
- Smart Guide 본문 잘림 또는 미표시

실패 시 보고할 사항:

- 화면 크기 및 설정
- stepId
- 실제 DOM 좌표
- 교차 면적
- 재현 순서
- 경고·콘솔 오류
- 관련 SDK 코드 위치
- 추정 원인과 근거

SDK 내부나 호스트 코드를 임의로 수정하지 마세요. 다음 수정이 필요하면 **v0.5.30**으로 별도 배포할 예정입니다.
