# 무인민원발급기 — 공통 SDK v0.3.4 적용 및 실제 사용성 문제 검증

첨부한 파일은 `@naebangsik/kiosk-accessibility-sdk@0.3.4`입니다.

현재 무인민원발급기에는 SDK v0.3.3이 설치되어 있습니다.

이번 작업은 새 SDK를 적용하고, 실제 QR 통합 테스트에서 발견했던 작은 글씨·작은 선택 버튼·추가 메뉴 안내 문제를 개선하는 것입니다.

## 1. SDK 업데이트

- 첨부된 tarball의 패키지명과 버전 확인
- SDK v0.3.4 설치
- 기존 v0.3.3 아카이브 보존
- SDK 패키지 내부 코드 수정 금지
- 기존 터치 스크롤 CSS 수정 유지

## 2. 설명문 확대 대상 등록

실제 사용자가 큰 글씨 모드를 적용해도 작다고 느낀 부분이 있습니다.

특히 주민등록표(등본) 발급 흐름의 다음 화면을 확인해 주세요.

- 증명서에 표시할 항목
- 주소 공개
- 과거 주소 변동 사항
- 세대 구성 사유
- 각 항목의 설명 문구
- 현재 선택 상태 요약
- 수수료 면제 단계의 설명 문구

현재 `getTextTargets()`가 이 텍스트를 제대로 등록하는지 확인하고, 누락된 요소를 등록해 주세요.

기존 SDK의 공통 글씨 확대 기능을 이용하고, 무인민원발급기 전용으로 글씨 크기를 강제 확대하는 CSS를 추가하지 마세요.

## 3. 작은 조작 버튼 확대

큰 버튼 모드에서 다음 조작부를 확인해 주세요.

- 주소 공개 선택 스위치
- 과거 주소 변동 사항 선택 스위치
- 세대 구성 사유 선택 스위치
- 수수료 면제 버튼
- 확인·이전·다음 단계 버튼

`getActions()`에 실제 조작 요소를 등록하고, SDK가 확대할 수 있게 연결해 주세요.

주의사항:

- 선택 상태 변경 로직 유지
- 기존 label과 접근성 이름 유지
- 클릭·터치 가능 영역 확대
- 인접 버튼끼리 겹치지 않음
- 한 화면의 모든 필수 조작 요소 유지
- SDK가 확대한 결과가 호스트 CSS 때문에 제한된다면 원인을 측정해 보고

업무 로직은 변경하지 마세요.

## 4. 추가 메뉴 안내 검증

기존 무인민원발급기에는 18개 증명서 메뉴가 있습니다.

SDK v0.3.4의 하단 안전 안내 기능을 연결해 다음을 확인해 주세요.

- QR 적용 전 기본 화면
- 큰 글씨·큰 버튼 적용 후
- 마지막 메뉴까지 스크롤
- 다시 맨 위로 스크롤
- 320×844
- 390×844
- 1080×1920

안내 문구:

"아래에도 증명서 메뉴가 있습니다. 화면을 위로 밀어보세요."

SDK가 실제 메뉴 위치와 스크롤 가능 여부를 정확히 판단해야 합니다.

안내가 나타나지 않는 경우 다음을 구분해 보고해 주세요.

A. 실제로 숨겨진 메뉴가 없음

B. 스크롤 불가능

C. 안내를 표시할 안전 공간이 없음

D. SDK 판정 오류

특히 기존에 안내가 브랜드·시계 헤더와 겹쳤던 문제도 확인해 주세요.

## 5. 주요 조작 버튼 안내

신규 SDK의 `primaryActions`를 실제 발급 화면에 선택적으로 연결해 주세요.

예시:

- 확인 버튼
- 다음 단계 진행 버튼
- 화면 아래로 스크롤해야 보이는 주요 실행 버튼

단, 이미 하단에 고정되어 보이는 버튼에 불필요한 안내를 표시하지 마세요.

호스트 전용 안내 UI를 새로 만들지 말고 SDK 기능을 사용해 주세요.

## 6. 기존 기능 회귀

다음 기능을 보존하고 확인해 주세요.

- 증명서 메뉴 18개
- QR v1/v2 프로필 적용
- 큰 글씨·큰 버튼·고대비
- 스마트 길잡이·음성 안내
- QR 없이 기본 이용
- 기존 터치 스크롤
- 개인정보 보호 안내
- 지문인식 시뮬레이션
- 주민등록표(등본) 발급 전체 과정
- 주문 중이 아닌 발급 도중 처음화면 → QR 설정 초기화
- 전화면 → QR 설정 유지
- 화면 단순화 기능 제거 상태

실제 중앙 QR 성공 응답과 모의 응답 검증은 구분해서 보고해 주세요.

## 7. 정밀 측정

320×844, 390×844, 1080×1920에서 다음을 측정해 주세요.

- 기본 글씨 크기
- 큰 글씨 적용 후 실제 글씨 크기
- 선택 스위치 클릭 영역
- 수수료 면제 버튼 크기
- 마지막 메뉴 위치
- 추가 메뉴 안내 표시 여부·좌표
- 헤더와 안내 겹침 여부
- 하단 버튼과 안내 겹침 여부
- 메뉴 클릭 hit-test
- 가로 넘침과 잘린 설명문

가능한 경우 확대 적용 전후를 픽셀 단위로 비교해 주세요.
