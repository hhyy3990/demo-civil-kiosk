# 무인민원발급기 — SDK v0.3.5 적용 및 범용 자동 확대·스크롤 안내 검증

첨부한 파일은 `@naebangsik/kiosk-accessibility-sdk@0.3.5`입니다.

현재 무인민원발급기에는 SDK v0.3.4가 적용돼 있습니다.

이번 작업은 SDK를 v0.3.5로 업데이트하고, 호스트에서 글씨를 개별 등록하지 않아도 자동 확대되는지, 세로 스크롤이 필요한 화면에서 안내가 정상 표시되는지 검증하는 것입니다.

## 1. SDK 업데이트

- 첨부 tarball의 패키지명과 버전 확인
- SDK v0.3.5 설치
- 이전 tarball 보존
- SDK 내부 소스 수정 금지
- 중앙 서버·DB 수정 금지
- 기존 터치 스크롤 CSS 및 발급 업무 로직 유지

## 2. 범용 글씨 자동 확대 검증

SDK v0.3.5는 키오스크 루트 안의 일반 텍스트를 자동 탐색해 확대하도록 변경됐습니다.

따라서 개별 텍스트 요소를 새로 등록하지 않은 상태에서 다음 화면의 글씨가 확대되는지 확인해 주세요.

- 첫 화면 증명서 메뉴 18개
- 개인정보 보호 안내
- 주민등록번호 입력 화면
- 지문 확인 안내
- 증명서에 표시할 항목
- 수수료 면제 안내
- 발급 부수 선택
- 결제 화면
- **신청 내용 확인 화면의 모든 요약 텍스트**
- 발급 완료 화면

특히 '신청 내용 확인' 화면은 사용자가 직접 확인한 확대 누락 사례입니다.

기존 어댑터에 이미 등록된 텍스트와 새 자동 탐지 대상은 구분해서 보고해 주세요.

자동 탐지 성능을 검증하기 위해 신청 내용 확인 화면에 새로운 getTextTargets() 등록을 추가하지 마세요.

### 실제 측정

기본 / 큰 글씨 / 아주 큰 글씨 모드에서 다음을 비교해 주세요.

- 제목
- 본문
- 보조 설명
- 표·요약 정보
- 금액과 수량
- 버튼 문구

각각 computed font-size를 px 단위로 측정하고, 확대 누락 요소와 그 이유를 보고해 주세요.

텍스트가 커졌다는 이유만으로 성공 처리하지 말고, 글씨 잘림·겹침·한 글자씩 세로 표시되는 문제도 확인해 주세요.

## 3. 세로 스크롤 안내 검증

이번 SDK는 등록 메뉴가 아니라 실제 세로 스크롤 가능 여부를 기준으로 안내합니다.

기본 문구:

"아래에도 내용이 있습니다. 화면을 위로 밀어보세요."

다음 조건에서 검증해 주세요.

- QR 적용 전 기본 화면
- 큰 글씨·큰 버튼 적용 후
- 세로 스크롤이 가능한 첫 메뉴 화면
- 발급 절차 중 아래쪽 내용이 생기는 화면
- 스크롤 끝에 도달한 상태
- 맨 위로 다시 돌아온 상태
- 화면 크기 변경으로 새로 스크롤이 발생한 상태

기대 결과:

- 실제 아래로 더 스크롤할 수 있으면 안내 표시
- 끝까지 이동하면 안내 사라짐
- 다시 위로 올라오면 재표시
- 기본 화면에서도 동작
- 글씨 확대 후에도 동작
- 헤더와 겹치지 않음
- 하단 고정 버튼을 가리지 않음
- 마지막 메뉴 클릭 방해 없음

이번에는 `no-safe-space` 때문에 표시가 사라지는 문제를 집중적으로 확인해 주세요.

## 4. 스크롤 안내의 하단 위치

무인민원발급기에는 처음화면·전화면·확인 등의 하단 고정 버튼이 있습니다.

SDK는 스크롤 안내를 이 버튼들 위에 표시해야 합니다.

- 실제 하단 조작부 좌표 측정
- 안내 좌표 측정
- 고정 버튼과 겹침 여부 확인
- 필요하면 안내가 일반 스크롤 콘텐츠 일부를 시각적으로 덮는 것은 허용
- 버튼 클릭·스크롤 자체는 방해하지 않아야 함
- 끝까지 스크롤하면 마지막 메뉴와 버튼 모두 이용 가능해야 함

안내가 나오지 않으면 단순히 '미표시'라고 보고하지 말고 원인과 진단값을 확인해 주세요.

## 5. 가로 안내 제거 확인

- '오른쪽에도 메뉴가 있습니다' 등 기존 가로 스크롤 안내가 나타나지 않아야 함
- 기존 발급 화면의 스크롤이나 선택 기능이 바뀌면 안 됨
- SDK가 새로운 화살표 버튼을 생성해서는 안 됨

무인민원발급기에 기존 다음 메뉴 탐색 버튼이 없다면 새로 만들 필요는 없습니다.

## 6. 기존 기능 회귀

- 증명서 메뉴 18개 유지
- QR v1/v2 모의 프로필 적용
- 큰 글씨·큰 버튼·고대비
- 스마트 길잡이·음성 안내
- 문서 스크롤과 터치 스와이프
- 발급 절차 전체
- 전화면 이동 시 접근성 설정 유지
- 처음화면 복귀 시 SDK endSession() 초기화
- 개인정보 및 지문인식 데모 안내 유지

320×844, 390×844, 1080×1920에서 확인해 주세요.

가능하면 QR 프로필 적용 상태에서 320 → 390 → 1080 → 390으로 크기를 바꾸고, 글씨 확대 누적 여부도 측정해 주세요.

## 8. 제한사항

- SDK 패키지 내부 수정 금지
- 신청 내용 확인 화면의 텍스트를 일일이 등록해서 성공 처리하지 않기
- 호스트 전용 글씨 확대 CSS 추가 금지
- 호스트 전용 스크롤 안내 UI 추가 금지
- 중앙 QR 서버·DB 수정 금지
- 하단 조작 모드 재설계 금지
- QR 설정 버튼 위치 변경 금지
- AI 기능 추가 금지
- Publish 금지

**이번 검증의 핵심은 별도 키오스크 맞춤 수정 없이도 일반 텍스트 확대와 스크롤 안내가 작동하는지 확인하는 것입니다.**

자동으로 적용되지 않는 부분은 임시방편으로 가리지 말고, SDK의 공통 개선 과제로 분리해 주세요.
