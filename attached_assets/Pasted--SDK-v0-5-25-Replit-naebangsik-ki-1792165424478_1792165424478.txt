# 무인민원발급기 — 공통 SDK v0.5.25 적용 및 상단 안내창 위치 최종 검증

현재 프로젝트는 **무인민원발급기 Replit**입니다.

첨부한 `naebangsik-kiosk-accessibility-sdk-0.5.25.tgz`를 이용해 기존 SDK v0.5.24를 v0.5.25로 업데이트해 주세요.

패키지명은 `@naebangsik/kiosk-accessibility-sdk`입니다.

이번 작업에서는 기존 호스트 코드와 안내 문구를 유지하면서, SDK 업데이트 및 위치 안정성 검증에만 집중합니다.

## 1. SDK 설치

- 첨부된 공식 v0.5.25 tarball 설치
- package.json 및 lockfile 갱신
- 기존 v0.5.24 tarball 보존
- SDK 내부 코드 수정 금지
- 타입 검사와 빌드 실행

## 2. 상단 안내 패널 위치 검증 — 최우선

이전에 사용자 테스트에서 하단 60% 모드의 쉬운 말 패널이 이전·다음 버튼을 누를 때마다 상단 40% 영역 안에서 위아래로 움직였습니다.

v0.5.25에서는 페이지 내용과 패널 높이가 바뀌더라도 고정된 상단 기준 위치를 유지하도록 SDK를 수정했습니다.

다음 조건에서 실제 브라우저 DOM의 패널 상단 Y 좌표를 측정하세요.

- 화면: 390×844
- 하단 조작 60%
- 매우 큰 글씨
- 큰 버튼
- 고대비
- 쉬운 말 및 스마트 길잡이 활성화

다음 상황을 각각 검증하세요.

1. 쉬운 말 1페이지 표시
2. 다음 버튼으로 2페이지 이동
3. 이전 버튼으로 1페이지 복귀
4. 여러 차례 페이지 왕복
5. 접기
6. 펼치기
7. 스마트 길잡이 시작
8. 스마트 길잡이 종료
9. 기존 쉬운 말 페이지 복원
10. 업무 화면 스크롤

**같은 업무 단계에서 상단 패널 Y 좌표가 변하지 않아야 합니다.**

하단 60% 기준으로 패널 상단이 약 8px에 유지되는지 확인하되, 실제 렌더링 값으로 검증하세요.

긴 설명은 잘리지 않고 패널 내부에서 스크롤할 수 있어야 합니다.

## 4. 기존 하단 스크롤 안내 유지

v0.5.24에서 해결된 하단 스크롤 안내는 변경하지 않습니다.

- 실제 업무 스크롤 영역 하단에서 12px 간격
- 더 내릴 내용이 있을 때 표시
- 스크롤 중 위치 점프 없음
- 끝에서 숨김
- 위로 돌아오면 재표시
- 버튼과 겹쳐도 표시
- 클릭 통과 유지
- 모달 스크롤 상태 정상 반영

상단 안내 패널을 수정하면서 하단 스크롤 안내가 다시 움직이면 실패입니다.

## 5. 스마트 길잡이 회귀

- 표시 전 10초 대기
- slowGuidance 활성 시 약 15초 표시
- 키패드·옵션·부수 조작 중 조기 종료되지 않음
- 스마트 길잡이는 단일 안내
- 종료 후 쉬운 말 페이지와 접힘 상태 복원
- 실제 업무 단계 전환 시 이전 안내 정리

## 6. 전체 발급 검증

실제 개인정보 없이 가상 입력값으로 진행하세요.

증명서 선택 → 숫자 입력 → 지문 시뮬레이션 → 표시 항목 → 수수료 면제 → 부수 선택 → 신청 내용 확인 → 결제 시뮬레이션 → 인쇄 → 완료 → 15초 후 처음 화면 복귀

기존 18개 증명서 메뉴를 유지하세요.

QR v1~v4 모의 프로필, QR 모달 확인 버튼, 세션 종료 후 설정 초기화도 재검증하세요.
