# 무인민원발급기 — 공통 SDK v0.5.14 설치 및 통합 안내창 연동

## 0. 작업 대상

현재 프로젝트는 **무인민원발급기 Replit**입니다.

첨부한 `naebangsik-kiosk-accessibility-sdk-0.5.14.tgz` 파일을 사용하여 기존 공통 접근성 SDK를 v0.5.14로 업데이트하고, 무인민원발급기 업무 단계에 새로운 공통 안내창을 연결해 주세요.

패키지명: `@naebangsik/kiosk-accessibility-sdk`

이 SDK는 별도 **데모커피 Replit**에서 개발한 범용 SDK입니다.

**이번 작업은 SDK 설치와 기존 호스트의 정상적인 API 연결만 수행합니다. SDK 내부 코드를 수정하거나 무인민원발급기 전용 안내창을 새로 만들지 마세요.**

## 1. 현재 프로젝트 분석

작업 전에 다음을 확인하세요.

- 현재 설치된 SDK 버전
- SDK import 및 초기화 구조
- QR 스캔·프로필 적용 방식
- `notifyScreenChange()` 연결
- `setGuideState()`와 단계별 `stepId`
- 기존 4단계 업무 흐름
- 키패드 및 입력값 표시 구조
- 하단 조작 60/70/80%
- QR 도크와 스크롤 안내
- 완료 후 15초 자동 복귀
- 시간 연장, 처음으로 돌아가기, `endSession()`
- 기존 테스트와 빌드 구조

기존 무인민원발급기 기능을 최대한 보존하세요.

## 2. SDK v0.5.14 설치

업로드된 tarball을 설치하세요.

설치 후 다음을 확인합니다.

- 실제 설치 패키지 버전이 `0.5.14`
- 패키지명 일치
- 기존 공개 API 호환성
- 신규 `setEasyLanguageState()` API 사용 가능
- QR 프로필 v1~v4 검증 지원
- `slowGuidance` 지원
- 타입 검사 및 빌드 성공

기존 SDK를 호스트에서 복제하거나 별도 패치하지 마세요.

SDK에 문제가 있다면 무인민원발급기 전용 임시 해결책을 만들지 말고 원인과 재현 조건을 보고하세요. 공통 SDK 문제는 추후 데모커피 원본에서 수정하겠습니다.

## 3. 4단계 쉬운 말 안내 연결

SDK의 신규 API를 사용합니다.

`setEasyLanguageState({ stepId, explanations })`

현재 설치된 SDK의 실제 타입 정의를 확인하여 올바른 형식으로 호출하세요.

아래 문구는 안내 예시입니다. 실제 화면에 존재하는 버튼·기능·용어와 정확하게 일치하도록 확인한 후 사용하세요.

### 1단계 — 숫자 키패드 입력

쉬운 설명 예시:

- **숫자 입력**: 화면의 숫자 버튼을 눌러 필요한 숫자를 입력하세요.
- **지우기**: 잘못 입력했다면 지우기 버튼으로 고칠 수 있어요.
- **확인**: 입력을 마쳤다면 확인 버튼을 누르세요.

단, 실제 화면에 지우기나 확인 버튼이 없다면 그 문구를 임의로 추가하지 마세요.

### 2단계 — 발급 옵션

쉬운 설명 예시:

- **발급 옵션**: 어떤 내용이 서류에 표시될지 고르는 것입니다.
- **표시 항목**: 서류에 넣을 정보를 선택하는 것입니다.

실제 화면의 옵션 명칭에 맞게 설명을 수정하세요.

### 3단계 — 발급 부수

쉬운 설명 예시:

- **발급 부수**: 서류를 몇 장 받을지 정하는 것입니다.
- **1부**: 서류 한 장을 뜻합니다.

실제 UI가 지원하는 발급 수량 선택 방식에 맞춰 설명하세요.

### 4단계 — 결제

쉬운 설명 예시:

- **결제**: 서류 발급에 필요한 금액을 내는 단계입니다.
- **결제 수단**: 돈을 내는 방법을 뜻합니다.
- **확인**: 결제 내용을 살펴보고 진행하세요.

실제 결제 방식과 시뮬레이션 범위를 확인하고, 실제 돈이 청구되거나 실물 서류가 발급되는 것처럼 오해할 표현은 피하세요.

### 단계 연결 규칙

- 기존 스마트 길잡이 `stepId`와 쉬운 말 안내 `stepId`를 일치시키세요.
- 업무 단계 변경 시 새 단계의 설명을 제공하세요.
- 이전 단계의 설명이 남지 않도록 하세요.
- 쉬운 설명이 여러 개면 SDK에서 자동으로 이전·다음 탐색을 제공합니다.
- 설명이 하나라면 불필요한 이전·다음 버튼을 표시하지 않습니다.
- 쉬운 설명이 필요한 문구가 없다면 빈 상태를 안전하게 처리합니다.
- 안내창의 위치·접기·펼치기·페이지 탐색·타이머는 SDK에서 관리합니다.

**호스트에서는 단계별 텍스트와 의미 있는 업무 상태만 전달하고, 안내창 표시 코드를 새로 만들지 마세요.**

## 4. 스마트 길잡이와 공통 안내창

기존 스마트 길잡이 연결을 유지하면서 새 안내창과 정상적으로 함께 작동하게 하세요.

기대 동작:

1. 쉬운 말 활성화 시 해당 단계 설명 표시
2. 스마트 길잡이 대기시간 경과
3. 기존 안내창에서 스마트 길잡이 내용으로 전환
4. 숫자 카운트다운 표시
5. 안내 종료 후 기존 쉬운 말 설명으로 복귀
6. 보고 있던 설명 번호와 접힘 상태 유지

`guideDelaySeconds`는 표시 전 대기시간 10/15/20초입니다.

`slowGuidance`는 표시 후 유지시간입니다.

- false: 10초
- true: 15초

두 시간을 혼동하지 마세요.

## 5. QR v4 프로필 호환

새 SDK의 QR v4 지원을 유지하세요.

신규 선호값:

- `language`: ko, zh, vi, en, th, uz, ja
- `stepByStepGuidance`: boolean
- `conciseGuidance`: boolean
- `slowGuidance`: boolean

기존 QR v1~v3도 계속 지원합니다.

현재 중앙 QR Production은 아직 v4로 배포되지 않았으므로, 실제 서버에 v4 QR이 존재한다고 가정하지 마세요.

v4 신규 설정을 모의 QR 응답으로 테스트할 수 있습니다.

중요:

- 실제 다국어 번역은 아직 구현되지 않았습니다.
- AI 맞춤 안내 문구 생성도 아직 구현되지 않았습니다.
- stepByStepGuidance와 conciseGuidance는 현재 선호값 보존이 목적입니다.
- slowGuidance만 이번 SDK에서 15초 표시 유지 동작에 실제 연결됩니다.

구현하지 않은 다국어·AI 기능을 이미 제공하는 것처럼 표시하지 마세요.

## 6. 키패드·주요 버튼 보호

가장 중요한 검증 항목입니다.

이전 SDK 검증에서 작은 화면의 하단 조작 60% 환경에서 안내창과 키패드가 겹치는 문제가 발견됐으며, v0.5.14의 공통 배치 로직에서 수정했습니다.

무인민원발급기에서도 다음 요소가 실제로 조작 가능한지 확인하세요.

- 숫자 키패드
- 입력한 숫자 표시 영역
- 확인·다음 버튼
- 뒤로 가기
- 발급 부수 선택
- 결제 버튼
- 화면 스크롤
- QR 도크

기존 SDK가 제공하는 주요 동작·회피 영역 등록 API를 확인하고, 실제 업무 조작 요소가 SDK에 정확히 등록되도록 연결하세요.

이것은 SDK가 제공하는 공개 연동 방식의 정상적인 사용이며 허용됩니다.

반면 호스트에서 안내창 CSS를 임의로 수정하거나 SDK 내부 선택자를 직접 조작하는 것은 금지합니다.

안내창 때문에 키패드나 중요한 버튼이 가려지는 문제가 발생하면 다음을 보고하세요.

- 화면 단계
- 화면 크기
- 하단 조작 비율
- 활성화된 접근성 설정
- 겹치는 요소
- SDK의 회피 영역 등록 여부

문제 재현을 위한 최소 사례를 남기고, 공통 SDK 수정이 필요한 부분은 별도로 보고하세요.

## 7. 접기·펼치기 및 이전·다음

실제 브라우저에서 다음 흐름을 확인하세요.

1. 쉬운 말 활성화
2. 설명 1/3 표시
3. 다음 버튼 클릭해 2/3 이동
4. 안내창 접기
5. 접힌 상태에서 스마트 길잡이 시작
6. 안내창이 강제로 펼쳐지지 않음
7. 스마트 길잡이 종료
8. 다시 쉬운 말 설명으로 복귀
9. 접힌 상태 유지
10. 펼치면 설명 2/3 유지

현재 단계에서 설명이 세 개보다 적다면 실제 설명 개수에 맞춰 검증하세요.

별도의 독립 테스트에서 설명 3개 시나리오를 구성해도 좋습니다.

## 8. 단계 전환 및 타이머 검증

- 키패드 → 발급 옵션
- 발급 옵션 → 발급 부수
- 발급 부수 → 결제
- 이전 단계로 돌아가기
- 같은 단계 재진입
- 빠른 화면 전환
- 스마트 길잡이 대기 중 화면 전환
- 스마트 길잡이 표시 중 화면 전환
- 세션 종료

오래된 안내가 남거나 이전 타이머가 새로운 안내를 종료시키면 안 됩니다.

## 9. 완료 후 자동 복귀 유지

기존 완료 흐름을 변경하지 마세요.

- 실제 시뮬레이션 발급 완료 이후 15초 카운트다운 시작
- 시간 연장 시 15초로 갱신
- 수동 처음으로 이동
- 자동 처음 화면 복귀
- `endSession()`으로 접근성 설정 초기화
- 스마트 길잡이 타이머 정리
- 쉬운 말 설명 및 접힘 상태 초기화

완료 카운트다운과 스마트 길잡이 카운트다운은 서로 별개입니다.

하나의 타이머가 다른 타이머를 중단시키면 안 됩니다.

다음 화면 크기를 확인하세요.

- 320×844
- 360×667
- 390×844
- 1080×1920

- 기본 화면

- 버튼 크게
- 고대비
- 쉬운 말

- 하단 조작 80%

모든 조합을 브라우저에서 검증할 수 없다면 검증된 조합과 미검증 조합을 구분해서 보고하세요.
