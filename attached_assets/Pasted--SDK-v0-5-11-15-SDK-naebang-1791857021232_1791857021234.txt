# 무인민원발급기 — SDK v0.5.11 설치 및 발급 완료 후 15초 자동 복귀 구현

현재 프로젝트는 무인민원발급기 시뮬레이션입니다.

현재 설치된 SDK는 `@naebangsik/kiosk-accessibility-sdk@0.5.10`입니다.

데모커피 프로젝트에서 제작한 SDK v0.5.11 tarball을 업로드했습니다.

이번 작업의 목적은 **민원발급과 영수증·출력 절차가 모두 완료된 뒤, 15초 후 자동으로 첫 화면으로 돌아가도록 구현하는 것**입니다.

가장 중요한 원칙은 **공통 SDK 우선**입니다.

무인민원발급기 전용 자동 복귀 타이머를 만들지 말고, SDK v0.5.11의 완료 세션 API를 사용하세요.

## 1. SDK 설치

업로드한 `naebangsik-kiosk-accessibility-sdk-0.5.11.tgz`의 실제 위치와 메타데이터를 확인하세요.

- 패키지명: `@naebangsik/kiosk-accessibility-sdk`
- 버전: `0.5.11`

정상 확인 후 기존 v0.5.10을 교체합니다.

- package.json·lockfile 업데이트
- node_modules 실제 설치 버전 확인
- 기존 v0.5.10 tarball 보존
- 기존 SDK API 호환성 확인

새 tarball이 없거나 버전이 일치하지 않으면 임의로 구현하지 말고 보고하세요.

## 2. SDK 완료 세션 API 확인

SDK의 실제 README와 타입 선언을 먼저 확인하세요.

다음 API를 기준으로 연결합니다.

- `beginCompletion()`
- `subscribeCompletion()`
- `extendCompletion()`
- `cancelCompletion()`
- `finishCompletion()`

각 함수의 정확한 인자·반환값·수명주기를 확인한 뒤 사용합니다. 예시를 보고 함수 시그니처를 추측하지 마세요.

SDK가 타이머를 관리하고, 호스트는 최종 완료 화면과 초기화 콜백만 연결해야 합니다.

## 3. 자동 복귀 시작 시점

다음 업무 흐름을 확인합니다.

증명서 선택 → 주민등록번호 입력 → 지문 확인 시뮬레이션 → 표시 항목 선택 → 발급 부수 선택 → 가상 결제 → 인쇄 중 → 발급 완료 → 영수증 관련 절차

**결제 완료 또는 인쇄 중인 시점에는 자동 복귀 타이머를 시작하지 마세요.**

실제 구현된 영수증 처리 단계가 있다면 해당 단계까지 끝난 다음 시작합니다.

영수증 별도 단계가 없다면, 모든 발급·출력 시뮬레이션이 완료되고 최종 완료 화면이 실제로 표시된 시점부터 시작합니다.

현재 호스트 코드의 실제 상태 전환을 분석해 안전한 시작 시점을 결정하세요.

## 4. 완료 화면 표시

기존 발급 완료 화면을 유지하면서 다음 안내를 추가합니다.

'15초 후 처음 화면으로 돌아갑니다.'

SDK가 제공하는 남은 시간을 초 단위로 표시합니다.

사용자 버튼:

- 시간 연장
- 처음 화면으로

시간 연장 버튼을 누르면 다시 15초부터 시작합니다.

처음 화면으로 버튼을 누르면 기다리지 않고 즉시 복귀합니다.

새 버튼은 기존 무인민원발급기 디자인과 접근성 스타일을 따르세요.

큰 글씨·큰 버튼·고대비·하단 60·70·80% 설정에서도 남은 시간과 버튼이 읽히고 클릭 가능해야 합니다.

이번 기능 구현을 위한 완료 화면의 최소 UI 변경은 허용하지만, 다른 업무 화면의 디자인은 변경하지 마세요.

## 5. 세션 초기화

자동 복귀 또는 수동 복귀 시 다음 상태를 초기화합니다.

- 증명서 종류
- 주민등록번호 입력 상태
- 표시 항목 선택
- 발급 부수
- 결제 방법
- 모의 영수증 및 출력 결과
- 이전 완료 화면 상태
- 접근성 QR 프로필
- 스마트 길잡이 및 강조
- 음성 안내
- 스크롤 위치

호스트의 업무 데이터 초기화와 SDK endSession()을 안전하게 연결하세요.

초기화에 실패할 경우 이전 사용자 정보가 남아 있는 첫 화면을 표시해서는 안 됩니다.

실제 주민등록번호를 사용하지 않으며 입력값이 로그에 남지 않도록 합니다.

## 6. 타이머 충돌 및 중복 방지

다음 조건을 검증합니다.

- 완료 화면 진입 시 스마트 길잡이 종료
- 완료 중 스마트 길잡이 재등장 금지
- 15초 뒤 자동 복귀 한 번만 실행
- 자동 복귀 직전 수동 복귀 시 중복 실행 없음
- 여러 번 시간 연장 가능
- 이전 완료 화면 타이머가 새 세션에 영향을 주지 않음
- 완료 화면에서 다른 화면으로 이동하면 타이머 취소
- endSession() 호출 이후 타이머 잔존 없음

호스트에서 별도 setTimeout 또는 setInterval로 자동 복귀를 구현하면 안 됩니다.

## 7. 실제 브라우저에서 15초 기다리는 검증

이번에는 SDK 단위 테스트뿐 아니라 실제 Chromium Preview에서 다음을 확인합니다.

**A. 자동 복귀**

- 발급 완료 및 영수증 절차 종료
- 15초 카운트다운 표시
- 사용자 조작 없이 실제 15초 대기
- 첫 화면으로 자동 복귀
- 이전 사용자 데이터 초기화

**B. 시간 연장**

- 완료 화면에서 몇 초 대기
- 시간 연장 버튼 클릭
- 15초부터 다시 카운트다운
- 연장된 시간까지 자동 복귀가 일어나지 않음

**C. 수동 복귀**

- 완료 화면에서 처음 화면 버튼 클릭
- 즉시 복귀
- 이후 이전 타이머가 남아 있지 않음

## 8. 화면 크기 및 접근성 검증

다음 크기를 확인합니다.

- 320×844
- 360×667
- 390×844
- 1080×1920
- 1440×900
- 1920×1080

접근성 설정:

- 기본
- 큰 글씨
- 매우 큰 글씨
- 큰 버튼
- 고대비
- 하단 60%
- 하단 70%
- 하단 80%

주요 조합을 실제 브라우저에서 확인하고, 수행하지 못한 조합은 미검증으로 보고하세요.

기존 사용자가 허용한 QR 도크·메뉴의 시각적 배치를 이번에 불필요하게 변경하지 마세요.

## 9. 전체 발급 업무 회귀

다음 흐름을 확인합니다.

초기 화면 → 증명서 선택 → 주민등록표 등본 → 가상 번호 입력 → 지문 확인 → 표시 항목 선택 → 수수료 확인 → 부수 선택 → 결제 방법 → 모의 결제 → 인쇄 중 → 발급 완료 → 영수증 처리 → 자동 또는 수동 처음화면 복귀

기존 SDK 기능을 유지합니다.

- QR v1/v2/v3
- 큰 글씨·매우 큰 글씨
- 큰 버튼·고대비
- 하단 60·70·80%
- 스마트 길잡이 stepId
- 스마트 길잡이 10초 자동 닫힘
- 스크롤 안내
- 선택적 글씨 크기 보정
- QR 도크 동기화
- 개발자 레이아웃 진단
- 세션 초기화
