# 무인민원발급기 — 공통 SDK v0.4.0 설치 및 방법 B 하단 조작 모드 검증

첨부한 파일은 `@naebangsik/kiosk-accessibility-sdk@0.4.0`입니다.

현재 무인민원발급기에는 SDK v0.3.6이 설치되어 있습니다.

이번 작업에서는 v0.4.0으로 업데이트하고, 새로운 공통 하단 뷰포트 기능을 무인민원발급기에서 검증하려고 합니다.

방법 B는 글씨와 버튼을 축소하지 않고 키오스크 화면을 아래쪽 60%·70%·80% 영역에서 사용할 수 있게 하는 기능입니다.

중앙 QR 서버와 프로필 스키마는 아직 수정하지 않습니다.

## 1. SDK 업데이트

- 첨부 tarball의 패키지명과 버전 확인
- v0.4.0 설치
- 기존 v0.3.6 및 이전 tarball 보존
- SDK 내부 소스 변경 금지
- 기존 발급 업무 로직 유지
- Publish 금지

## 2. 무인민원발급기 레이아웃 분석

방법 B를 연결하기 전에 다음 구조를 조사해 주세요.

- 키오스크 화면 최상위 루트
- 실제 문서 및 내부 스크롤 소유 요소
- 상단 헤더
- 기존 하단 고정 조작부
- 주민등록번호 숫자 키패드
- 증명서 메뉴 18개
- QR 설정 및 카메라 모달
- 개인정보 보호 안내
- 스마트 길잡이 및 세로 스크롤 안내
- 기존 position: fixed / sticky 요소

이후 SDK의 공개 viewport API와 기존 어댑터를 연결해 주세요.

카페 전용 CSS나 선택자를 복사하지 말고, 무인민원발급기의 실제 DOM에 맞는 최소 연결만 구현합니다.

## 3. 방법 B 적용

다음 세 비율을 각각 적용합니다.

- 60%
- 70%
- 80%

SDK에서 공개한 viewportMode 또는 setViewportMode()를 사용해 주세요.

이번에는 개발 전용 테스트 옵션으로만 적용하며, 일반 QR 사용자에게 자동으로 활성화하지 마세요.

기존 QR의 bottomControls 값만으로 방법 B가 켜져서는 안 됩니다.

기본 화면과 개발용 테스트 화면은 분리해 주세요.

## 4. 큰 글씨·큰 버튼 동시 적용

다음 조합을 검증합니다.

- 70% 기본 글씨
- 70% 큰 글씨
- 70% 아주 큰 글씨
- 70% 큰 버튼
- 70% 아주 큰 글씨 + 큰 버튼 + 고대비
- 60% 아주 큰 글씨 + 큰 버튼
- 80% 아주 큰 글씨 + 큰 버튼

글씨와 버튼의 computed style 및 실제 bounding rectangle을 측정해, 하단 모드 적용 전후 크기가 줄어들지 않는지 확인해 주세요.

## 5. 스크롤 안정성

이전 SDK에서 스크롤을 끝까지 내렸을 때 자동으로 튀어 올라오는 문제가 있었습니다.

다음 사항을 반드시 검증해 주세요.

- 마지막 증명서 메뉴까지 스크롤 가능
- 최하단에서 0.1초·0.5초·1초·3초 위치 유지
- 스크롤 안내 끝 위치에서 숨김
- 다시 위로 이동하면 안내 재표시
- 하단 고정 버튼 접근 가능
- 사용자 스크롤을 SDK가 강제로 되돌리지 않음
- 스크롤 안내가 필수 버튼을 가리지 않음

실제 스크롤 소유 요소와 스크롤 좌표를 기록해 주세요.

## 6. 숫자 키패드 및 하단 고정 버튼 검증

무인민원발급기에는 기존에 다음 문제가 있습니다.

- 큰 글씨 프로필에서 주민등록번호 숫자 키패드 일부가 하단 고정 버튼 뒤에 위치
- 하단 고지 문구가 처음화면·전화면·확인 버튼과 겹침

이번에는 방법 B에서 이러한 문제가 어떻게 나타나는지 정확하게 측정해 주세요.

특히 다음을 확인합니다.

- 숫자 키패드 모든 숫자에 접근 가능
- 실제 입력 터치 가능
- 하단 처음화면·전화면·확인 버튼 클릭 가능
- 하단 고지 문구와 조작부 겹침 위치
- 안내 pill이 키패드나 필수 버튼을 가리지 않음

**기존 하단 고지 문구의 호스트 CSS 문제는 이번 작업에서 임의로 수정하지 말고, 방법 B 적용 전후의 차이를 보고해 주세요.**

## 7. 모달 및 스마트 길잡이

- QR 촬영·직접 입력 모달이 하단 표시 영역 안에 나타나는지 확인
- 고정 하단 버튼을 가리지 않는지 확인
- 스마트 길잡이가 표시되면 스크롤 안내 숨김
- 스마트 길잡이가 사라지면 스크롤 상태에 따라 안내 복귀
- 안전한 위치가 없으면 기존 필수 조작을 우선 보호
- 안내 표시·숨김으로 스크롤 위치 변경 금지

## 8. 발급 전체 흐름 검증

70% 기본 모드와 70% 아주 큰 글씨·큰 버튼·고대비 모드에서 다음을 검증해 주세요.

- 증명서 메뉴 선택
- 개인정보 안내
- 주민등록번호 테스트 입력
- 가상 지문 확인
- 표시 항목 선택
- 수수료 면제 여부 선택
- 발급 부수 선택
- 신청 내용 확인
- 가상 결제
- 인쇄 및 발급 완료
- 처음화면 복귀

60%와 80%에서도 주요 단계와 필수 조작 버튼을 검증해 주세요.

실제 개인정보는 입력하거나 로그에 남기지 마세요.
