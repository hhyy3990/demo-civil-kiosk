# 가상 무인민원발급기 — 내 방식 QR SDK v0.2.0 설치 및 1차 범용성 검증

현재 프로젝트는 접근성 기능 없이 독립적으로 제작한 한국형 가상 무인민원발급기입니다.

별도 데모커피 프로젝트에서 제작한 공통 접근성 SDK v0.2.0 파일을 프로젝트 루트에 업로드했습니다.

파일명:
`naebangsik-kiosk-accessibility-sdk-0.2.0_1791611089591.tgz`

이번 작업의 목적은 이미 완성된 독립적인 무인민원발급기에 **동일한 SDK를 적용했을 때 얼마나 적은 수정으로 접근성 기능을 구현할 수 있는지 검증하는 것**입니다.

## 1. SDK 설치

업로드한 .tgz 파일을 npm으로 설치해 주세요.

설치 전 파일 내부의 package.json과 exports를 확인하고, 패키지명과 버전이 `@naebangsik/kiosk-accessibility-sdk@0.2.0`인지 검증해 주세요.

기존 SDK 소스나 패키지 내부 코드는 수정하지 마세요.

SDK CSS와 공개 API만 사용해 주세요.

## 2. SDK 적용

기존 무인민원발급기의 업무 로직과 디자인은 그대로 유지하면서, SDK를 연결해 주세요.

호스트 어댑터는 다음 사항을 전달하도록 구성합니다.

- 현재 발급 단계
- 현재 단계의 사용 가능한 버튼과 의미 ID
- 강조할 버튼의 DOM 참조
- 화면의 주요 텍스트 요소
- 하단 조작 영역과 스크롤 영역
- 길잡이에 필요한 최소 상태

주민등록등본 발급 기능, 임의 숫자 입력, 지문 시뮬레이션, 옵션 선택, 발급 부수, 결제 및 인쇄 흐름은 변경하지 마세요.

## 3. QR 스캔 및 프로필 연동

SDK v0.2.0에 포함된 공통 QR 스캐너를 사용해 주세요.

- 초기 화면에만 '내 QR로 화면 설정' 버튼 추가
- 버튼을 누르면 QR 카메라 스캔 화면 표시
- 카메라가 없거나 권한이 거부되면 QR 주소 직접 입력 가능
- 공식 중앙 서비스 주소만 허용
- SDK의 QR 검증·조회 API 사용
- same-origin 서버 중계로 중앙 '내 방식 QR'의 프로필 조회
- 조회된 설정을 SDK의 검증 함수로 확인한 뒤 적용
- QR 스캔 성공 시 카메라 즉시 종료
- QR 토큰이나 관리 코드를 로그에 출력하지 않기

중앙 서비스:
https://naebangsikqr.replit.app

중앙 QR 서버의 기존 API 규격을 정확히 확인하고, 현재 SDK와 호환되는 요청·응답을 사용해 주세요. 추측한 API 형식으로 구현하지 마세요.

QR 적용 후에도 사용자가 주민등록등본 발급 절차를 정상 진행할 수 있어야 합니다.

## 4. 1차 범용성 검증

SDK를 적용한 직후 상태를 기준으로 다음 기능을 점검해 주세요.

- 기본 화면 유지
- 큰 글씨
- 큰 버튼
- 고대비
- 하단 조작
- 화면 단순화
- 스마트 길잡이
- 음성 안내
- 카메라 QR 인식
- SDK 레이아웃 진단

특히 첫 화면의 18개 증명서 메뉴를 모두 보존해 주세요. 화면 단순화가 켜져도 증명서 버튼을 임의로 제거하거나 숨기지 마세요.

큰 글씨 상태에서 버튼이 가려지거나 글자가 잘리는지 확인해 주세요.

레이아웃 진단 결과와 실제 화면 검사를 구분해서 기록해 주세요.

## 5. 가장 중요한 실험 원칙

이번 작업은 접근성 기능을 미리 고려하지 않은 키오스크에 공통 SDK를 적용하는 실험입니다.

따라서 SDK 적용 중 화면 잘림, 버튼 겹침, 하단 조작 문제 등이 발견되면:

1. 문제를 기록하고 해당 화면과 설정을 식별합니다.
2. 가능하다면 적용 직후 화면을 캡처합니다.
3. SDK 공통 기능의 한계인지, 키오스크 어댑터의 연결 문제인지 구분합니다.
4. 원인을 보고합니다.
5. 별도 승인 없이 키오스크 고유 CSS를 대규모 수정하거나 문제를 임의로 감추지 마세요.

단, QR 연결에 필요한 최소 UI 및 어댑터 코드는 추가할 수 있습니다.
