# 무인민원발급기 — SDK v0.3.5.1 긴급 안정화 버전 적용

첨부한 파일은 `@naebangsik/kiosk-accessibility-sdk@0.3.5.1`입니다.

현재 무인민원발급기에는 SDK v0.3.5가 적용되어 있습니다.

데모커피에서 v0.3.5.1을 설치한 뒤 실제 QR을 사용해 확인했으며, 스크롤이 자동으로 튀어 오르는 오류가 사라지고 스크롤 안내도 정상 작동했습니다.

이번에는 같은 SDK를 무인민원발급기에 적용하여 기존 오류가 해결되는지 검증해 주세요.

## 1. 패키지 교체

- 첨부된 tarball의 패키지명과 버전 확인
- 기존 v0.3.5를 v0.3.5.1로 교체
- 이전 SDK 아카이브 보존
- SDK 내부 코드 수정 금지
- 기존 발급 업무 로직과 CSS 유지

## 2. 스크롤 튐 오류 검증 — 최우선

QR의 아주 큰 글씨·큰 버튼·고대비 설정을 적용한 상태에서 다음을 확인해 주세요.

- 손가락으로 아래로 스크롤
- 페이지를 맨 아래까지 이동
- 스크롤을 멈춘 뒤 0.1초, 0.5초, 1초, 3초 대기
- 사용자 입력 없이 스크롤이 중간으로 되돌아오는지 확인
- 마지막 증명서 메뉴 및 필수 확인 버튼 클릭 가능 여부
- 안내 UI가 표시·숨김될 때 스크롤 좌표가 변하는지 확인

320×844, 390×844, 1080×1920에서 테스트해 주세요.

실제 스크롤 소유 요소의 scrollTop, scrollHeight, clientHeight, 최대 스크롤 거리를 측정하고 결과를 보고해 주세요.

테스트 스크립트가 스크롤을 계속 강제로 재설정해 문제를 숨기지 않도록 해 주세요.

## 3. 스크롤 안내 검증

SDK의 안내 문구는 다음 두 가지만 사용합니다.

- "아래에도 내용이 있습니다. 화면을 위로 밀어보세요."
- "아래에도 버튼이 있습니다. 화면을 위로 밀어보세요."

확인 사항:

- QR 적용 전에도 스크롤이 필요하면 안내 표시
- QR 적용 후 스크롤이 생기면 안내 표시
- 맨 아래에 도달하면 안내 숨김
- 위로 다시 올리면 안내 재표시
- 상단 헤더와 겹치지 않음
- 처음화면·전화면·확인 버튼을 가리지 않음
- 안내 표시·숨김 때문에 스크롤이 튀지 않음

호스트별 '증명서 메뉴' 전용 문구를 다시 추가하지 마세요.

## 4. 글씨 확대 및 접근성 기능 유지

- SDK 자동 텍스트 확대 유지
- 신청 내용 확인 화면의 표·금액·작은 안내문 확대
- 큰 글씨·아주 큰 글씨·큰 버튼·고대비
- 개인정보 보호 및 지문인식 안내
- 스마트 길잡이·음성 안내
- QR v1/v2 프로필 처리
- 기존 터치 스크롤 CSS
- 증명서 메뉴 18개 유지

기존 큰 글씨 적용 시 고정 하단 고지 문구가 버튼과 겹치는 문제는 별도 개선 대상으로 남겨 주세요. 이번 작업에서는 원인과 현재 상태를 보고만 하고, 호스트 CSS를 수정하지 마세요.

## 5. 전체 발급 회귀

실제 브라우저에서 다음을 검증해 주세요.

- QR 없이 주민등록표(등본) 발급
- QR 모의 프로필 적용 후 발급
- 주민등록번호 테스트 숫자 입력
- 가상 지문 확인
- 증명서 표시 항목 선택
- 수수료 면제 여부 선택
- 발급 부수 선택
- 신청 내용 확인
- 가상 결제
- 인쇄 및 발급 완료
- 전화면 이동 시 QR 설정 유지
- 발급 중 처음화면 이동 시 QR 설정 초기화
- 발급 완료 후 처음화면 이동 시 초기화

실제 개인정보는 입력하거나 기록하지 마세요.

## 6. 실환경 검증 구분

자동화 브라우저에서 QR API를 모의 응답으로 대체했다면 실제 중앙 QR 연동 성공으로 보고하지 마세요.

실제 카메라 스캔, Production 중앙 서버의 성공 응답, 물리 터치스크린 검증은 각각 별도로 구분해 주세요.
