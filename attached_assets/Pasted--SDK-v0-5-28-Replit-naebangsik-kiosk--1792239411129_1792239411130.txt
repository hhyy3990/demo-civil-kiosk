# 무인민원발급기 — 최신 SDK v0.5.28 설치 및 실제 화면 최종 검증

현재 프로젝트는 **무인민원발급기 Replit**입니다.

첨부한 `naebangsik-kiosk-accessibility-sdk-0.5.28.tgz`는 데모커피 공통 SDK에서 무한 재귀 렌더링 오류를 수정한 최신 검증용 후보입니다.

패키지 버전: 0.5.28
파일 크기: 87,483 bytes

이번 작업은 최신 SDK 설치와 기존 오류 검증만 수행합니다.

**새 기능, 디자인, 쉬운 말 문구, 업무 로직, 호스트 CSS는 변경하지 마세요.**

## 1. 설치 확인

1. 기존 SDK v0.5.28 패키지를 보존하세요.
2. 첨부한 최신 v0.5.28 tarball을 설치하세요.
3. 같은 버전이므로 이전 캐시가 남지 않도록 정상적인 빌드·개발 서버 재시작을 수행하세요.
4. 패키지 파일 크기와 해시를 확인하세요.
5. 실제 브라우저가 최신 SDK 코드를 로드하는지 확인하세요.
6. 타입 검사 및 프로덕션 빌드를 실행하세요.

## 2. 첫 화면 검증

사용자가 승인한 규칙은 다음과 같습니다.

- 쉬운 말 켜기 + 하단 조작 미설정 → 첫 화면 포함 자동 하단 80%
- 명시적 60·70·80% → 사용자 선택 유지
- 쉬운 말 끄기 + 하단 조작 미설정 → 일반 화면

첫 메뉴 화면에서는 긴 설명 대신 다음 안내만 표시합니다.

제목: 쉬운 말 안내가 켜져 있어요.

본문: 업무를 선택하면 어려운 말을 쉽게 설명해 드려요.

먼저 공통 SDK에서 이 문구가 표시되는지 확인하세요.

현재 무인민원발급기 호스트가 첫 메뉴에 다른 안내를 전달하거나 안내를 비워 두어 문구가 표시되지 않는다면, **호스트에 필요한 최소 연결 변경만 구체적으로 보고하고 사용자 승인을 기다리세요.**

SDK에 `civil.main-menu` 등의 화면 ID를 하드코딩하지 마세요.

## 3. 기존 쉬운 말 분할 오류

실제 무인민원발급기의 다음 두 화면을 검증하세요.

- `certificate.type-selection`
- `certificate.id-input`

화면 크기:

- 320×844
- 360×667
- 390×844

설정:

- 매우 큰 글씨
- 큰 버튼
- 고대비
- 쉬운 말 켜기
- 스마트 길잡이 켜기
- 하단 80%

확인:

1. 66·137페이지와 같은 비정상적인 분할 재발 여부
2. 원문 누락·중복 없음
3. 본문·제목·페이지 버튼 잘림 없음
4. 한 글자씩 분할 없음
5. 이전·다음 버튼 정상
6. 패널 상단 Y=8px 유지
7. 페이지 전환 중 위치 점프 없음
8. 무한 재귀 및 브라우저 오류 없음

## 4. 긴 스마트 길잡이 검증

실제 무인민원발급기의 기존 긴 스마트 길잡이 문구를 그대로 사용하세요.

특히 하단 80%에서:

- 문구 전체 표시 여부
- 본문이 패널 하단에서 잘리는지
- 상단 고정 위치 유지
- 스마트 길잡이 표시 시간이 정상인지
- 쉬운 말을 접은 상태에서도 스마트 길잡이가 자동 펼쳐지는지
- 스마트 길잡이 종료 후 쉬운 말이 기존 접힘 상태로 돌아오는지

**긴 문구가 잘리면 임의로 문구를 줄이거나 스마트 길잡이를 여러 페이지로 변경하지 마세요.**

실제 문구, 표시 영역 크기, 잘린 픽셀 수를 보고하고 추가 수정은 보류하세요.

## 5. 기존 기능 회귀

## 6. 오류 발견 시

SDK 공통 결함이라면 무인민원발급기에서 우회 수정하지 마세요.

재현 조건과 실제 DOM 측정값을 보고한 뒤 중단하세요.

특히 이전에 해결한 상단 패널 위치 점프, 하단 스크롤 안내 위치 점프, 한 글자씩 분할, 무한 재귀 문제가 재발하지 않도록 확인하세요.
