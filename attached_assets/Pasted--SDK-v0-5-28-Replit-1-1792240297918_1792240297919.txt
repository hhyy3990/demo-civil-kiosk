## 2. 첫 메뉴 쉬운 말 안내 변경

현재 무인민원발급기 호스트는 첫 메뉴 화면 `civil.main-menu`에서 `setEasyLanguageState()`를 통해 기존 '증명서 선택' 안내를 전달합니다.

사용자가 승인한 첫 메뉴 안내는 다음과 같습니다.

제목: 쉬운 말 안내가 켜져 있어요.

본문: 업무를 선택하면 어려운 말을 쉽게 설명해 드려요.

첫 메뉴에서 쉬운 말이 활성화된 경우 위 문구를 한 페이지로 표시하세요.

- 기존 `setEasyLanguageState()` API 이용
- `civil.main-menu`에 해당하는 안내 데이터만 변경
- 첫 메뉴에서만 표시
- 업무 단계로 진입하면 기존 단계별 설명 복원
- 쉬운 말이 꺼져 있으면 안내 표시하지 않음
- 새로운 스마트 길잡이 문구 추가 금지
- SDK 내부에 `civil.main-menu` 하드코딩 금지
- 호스트의 다른 안내 문구 변경 금지

## 3. 자동 하단 80% 유지

공통 SDK의 다음 동작을 유지하세요.

- 쉬운 말 켬 + viewportMode null → 첫 화면 포함 하단 80%
- 명시적 60·70·80% → 해당 설정 유지
- 쉬운 말 끔 + viewportMode null → 일반 화면
- QR 원본 설정 변경 없음

## 4. 실제 쉬운 말 안내 검증

다음 두 화면의 기존 설명을 그대로 사용해 검증하세요.

- `certificate.type-selection`
- `certificate.id-input`

화면 크기:

- 320×844
- 360×667
- 390×844

확인 항목:

- 66·137페이지 오류 재발 없음
- 원문 누락·중복 없음
- 한 글자 분할 없음
- 본문 및 버튼 잘림 없음
- 상단 패널 Y 좌표 안정성
- 페이지 전환 시 점프 없음
- 무한 재귀 오류 없음

## 5. 스마트 길잡이 검증

실제 기존 스마트 길잡이 문구를 사용하세요.

- 긴 설명이 아래에서 잘리지 않는지
- 쉬운 말을 접은 상태에서도 Smart Guide가 시작되면 자동 펼쳐지는지
- Smart Guide 종료 후 원래 쉬운 말 접힘 상태로 복원되는지
- 10초 대기, slowGuidance 시 15초 표시 유지
- 입력·스크롤 중 조기 종료 없음

긴 문구가 잘리면 SDK 문제로 보고하고 임의로 호스트에서 우회하지 마세요.
