# 무인민원발급기 — 공통 SDK v0.5.24 최종 적용 및 전체 접근성 검증

현재 프로젝트는 **무인민원발급기 Replit**입니다.

첨부한 `naebangsik-kiosk-accessibility-sdk-0.5.24.tgz`를 사용해 공통 SDK를 기존 **v0.5.20에서 v0.5.24로 업데이트**해 주세요.

패키지명: `@naebangsik/kiosk-accessibility-sdk`

v0.5.24는 데모커피 프로젝트에서 스크롤 안내의 위치 안정성, 안내 패널 버튼 크기, 일반·하단 조작 모드의 동작을 검증한 버전입니다.

이번 작업은 **SDK 설치 → 무인민원발급기 실제 화면 검증 → 필요한 호스트 연결 및 쉬운 말 안내 개선** 순서로 진행합니다.

## 1. 최우선 원칙: SDK-first

공통 SDK의 결함을 무인민원발급기 호스트 코드에서 임시방편으로 해결하면 안 됩니다.

허용되는 호스트 수정:
- SDK 공개 API 연결
- 실제 업무 단계의 stepId 정리
- 화면별 쉬운 말·스마트 길잡이 안내 데이터
- 실제 업무 버튼·스크롤 영역·모달 등록

금지되는 수정:
- SDK 내부 소스 직접 수정
- 안내창 전용 CSS 덮어쓰기
- 특정 화면에 맞춘 안내 위치 하드코딩
- 스크롤 이벤트로 강제 위치 이동
- 공통 안내 기능을 호스트에서 별도 구현

SDK 결함이 확인되면 재현 조건과 DOM 측정값을 보고하고, 데모커피의 공통 SDK에서 수정할 수 있도록 작업을 중단해 주세요.

현재 프로젝트의 설치 상태와 SDK 연결 구조를 먼저 확인하세요.

- 하단 조작 60·70·80%

- 스마트 길잡이

- 음성 안내 및 세션 종료

이후 업로드된 공식 v0.5.24 tarball을 설치하세요.

`package.json`, lockfile을 업데이트하고 기존 v0.5.20 tarball을 보존하세요.

설치 버전과 파일 무결성을 확인하고 타입 검사·빌드를 실행하세요.

## 3. 스크롤 안내 v0.5.24 검증 — 가장 중요

이전 무인민원발급기에서 다음 오류가 발생했습니다.

- 스크롤 안내가 화면 상단·중앙·하단을 반복해서 이동
- 주민등록 유형 화면에서 한 번 스크롤할 때 약 380px 점프
- 쉬운 말이 있으면 스크롤 안내가 사라짐
- 하단 70·80%에서 공간 부족으로 안내가 숨겨짐

v0.5.24에서는 안내를 등록된 실제 스크롤 영역의 하단에서 **12px 위에 고정**하는 방식으로 변경했습니다.

### 반드시 확인할 정책

- 아래에 더 볼 내용이 있으면 스크롤 안내 표시
- 쉬운 말·스마트 길잡이와 함께 표시 가능
- 주요 버튼과 겹친다는 이유로 숨기지 않음
- 스크롤 안내는 클릭을 가로채지 않음
- 같은 화면에서 스크롤하는 동안 위치가 안정적으로 유지됨
- 스크롤 끝에서는 숨김
- 다시 위로 스크롤하면 원래 위치에 복귀
- 일반 화면 및 하단 60·70·80% 지원
- 모달이 열리면 배경 화면이 아닌 활성 모달의 스크롤 상태를 기준으로 표시

**사용자는 스크롤 안내가 업무 버튼과 시각적으로 겹치는 것을 허용했습니다. 따라서 버튼과 겹친다는 이유로 스크롤 안내를 숨기거나 다른 위치로 이동시키지 마세요.**

### 실제 무인민원발급기 브라우저 검증

다음 화면에서 실제 스크롤을 수행하세요.

1. 증명서 메뉴 목록
2. 주민등록 유형
3. 주민등록번호 키패드
4. 지문 확인
5. 증명서 표시 항목
6. 수수료 면제
7. 발급 부수
8. 신청 내용 확인
9. 결제
10. 완료

각 화면마다 실제로 스크롤이 가능한지부터 구분하세요.

스크롤 가능한 화면에서는 다음을 기록하세요.

- 스크롤 소유자
- scrollHeight
- clientHeight
- scrollTop
- 스크롤 안내 boundingRect
- 안내 하단과 업무 영역 하단 사이 거리
- 스크롤 전·중·후 Y 좌표
- 스크롤 끝에서 숨김 여부
- 다시 위로 이동했을 때 재표시 여부

**390×844, 하단 60% 조건에서 이전에 발생했던 약 380px 위치 점프가 다시 발생하지 않는지 반드시 확인하세요.**

## 4. 안내 패널과 버튼 크기 확인

v0.5.24의 공통 안내 패널 구조를 유지합니다.

- 접기·펼치기 버튼 실제 높이 44px
- 이전·다음 버튼 실제 높이 44px
- 닫기 버튼 실제 높이 44px
- 최소 44×44px 터치 영역
- 쉬운 말 본문 글씨 크기 유지
- 스마트 길잡이 단일 안내
- 스마트 길잡이에는 이전·다음 및 페이지 번호 없음

큰 글씨·큰 버튼·고대비를 함께 적용한 상태에서도 실제 버튼 크기와 글자 잘림을 확인하세요.

무인민원발급기 호스트 CSS로 안내 버튼 크기를 조정하지 마세요.

## 5. 스마트 길잡이 조기 종료 회귀 검증

이전에 다음 화면에서 스마트 길잡이가 15초 전에 사라졌습니다.

- 숫자 키패드
- 증명서 표시 항목 선택
- 발급 부수 선택

v0.5.20부터 수정된 기능이 v0.5.24에서도 유지되는지 확인하세요.

Development 체험 프로필 기준:

- guideDelaySeconds: 10
- slowGuidance: true
- 스마트 길잡이 표시 시간: 15초

스마트 길잡이가 시작된 상태에서 같은 화면의 숫자 입력·선택·부수 변경·스크롤을 반복하세요.

동일 단계의 조작에서는 안내가 약 15초 동안 유지되어야 합니다.

실제 다음 업무 단계로 이동하면 이전 안내는 종료되어야 합니다.

호스트에서 불필요하게 notifyScreenChange()를 호출하거나 stepId를 변경하고 있다면 공개 API 연결만 바로잡으세요.

## 6. 쉬운 말 안내 문구 개선

사용자는 기존 쉬운 말이 스마트 길잡이와 너무 비슷하고 실제 화면의 용어나 선택지를 충분히 설명하지 못한다고 지적했습니다.

이번에는 무인민원발급기 화면의 쉬운 말 설명을 검토하고, **실제 화면에 존재하는 어려운 용어·선택지의 의미를 쉽게 설명하도록** 개선해 주세요.

단, AI API는 아직 연결하지 않습니다.

### 역할 구분

**쉬운 말**
- 어려운 말의 뜻 설명
- 선택지가 의미하는 내용 설명
- 사용자가 이해하기 어려운 개념 설명

**스마트 길잡이**
- 지금 해야 할 행동 안내
- 다음 단계로 가는 방법 안내
- 현재 화면에서 눌러야 할 버튼 안내

두 기능이 같은 행동 지시를 반복하지 않도록 합니다.

### 주요 화면별 개선 방향

**주민등록번호 키패드**
- 주민등록번호가 무엇인지 간단히 설명
- 실제 번호를 안내에 다시 표시하지 않음
- 숫자 입력 순서 안내는 스마트 길잡이에서 제공

**지문 확인**
- 지문 확인이 본인인지 확인하는 방법이라는 점 설명
- 실제 지문 인식이 아닌 시뮬레이션임을 오해하지 않도록 유지

**증명서 표시 항목**
- '표시'와 '미포함' 등 실제 선택지의 차이를 설명
- 어떤 정보가 서류에 나타나는지 쉽게 설명
- 실제 화면에 없는 항목은 설명하지 않음

**수수료 면제**
- 수수료는 서류를 발급받을 때 내는 돈
- 면제는 조건에 해당하면 돈을 내지 않아도 되는 것
- 실제 선택지와 면제 조건을 임의로 만들어 설명하지 않음

**발급 부수**
- '1부'는 서류 한 장이라는 뜻
- '2부'는 서류 두 장이라는 뜻
- 장수를 선택하는 행동 지시는 스마트 길잡이에서 제공

**신청 내용 확인**
- 신청 내용은 지금까지 선택한 증명서와 옵션을 모아 보여주는 것
- 확인 화면에 실제 표시되는 정보만 설명

**결제**
- 실제 무인민원발급기에 표시되는 결제 방법과 수수료를 기준으로 설명
- 화면에 없는 결제 방법이나 영수증 내용을 임의로 설명하지 않음

### 전체 안내 데이터 점검

위 화면 외에도 기존 18개 증명서 메뉴의 공통 발급 흐름에서 안내 문구가 실제 화면과 맞는지 확인하세요.

- 해당 화면에 없는 용어 설명 제거
- 스마트 길잡이와 중복되는 행동 지시 제거
- 어려운 용어는 짧고 일상적인 표현으로 변경
- 한 페이지에는 한 개념 중심으로 설명
- 설명이 여러 개인 경우 기존 페이지 이동 기능 활용
- 쉬운 말 설명이 불필요한 화면에는 억지로 추가하지 않음

새로운 민원발급 기능이나 실제 행정 규칙을 임의로 만들지 마세요.

## 7. QR 모달 및 프로필 적용

이전 버전에서 QR 설정 확인 모달의 버튼이 안내 패널에 가려지는 문제가 있었습니다.

기존 호스트 공개 API 연결을 유지하면서 다음을 확인하세요.

- QR 프로필 적용 후 확인 모달 표시
- 확인 버튼 실제 클릭
- 모달 뒤의 쉬운 말 안내가 조작을 방해하지 않음
- 모달 닫은 뒤 현재 화면의 설명 복원
- QR v1~v4 모의 프로필 적용
- QR 도크 정상 동작
- 실제 스크롤 가능한 모달에서 스크롤 안내 정상 표시
- 모달에 스크롤할 내용이 없으면 스크롤 안내 미표시

모의 QR 토큰은 SDK 최소 길이 검사를 충족해야 합니다. 짧은 테스트 토큰으로 인해 API 호출이 실패하는 상황을 SDK 결함으로 오인하지 마세요.

실제 중앙 QR API와 실제 카메라 촬영은 이번 작업 범위 밖입니다.
