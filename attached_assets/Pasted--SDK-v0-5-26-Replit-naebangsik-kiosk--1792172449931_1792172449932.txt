# 무인민원발급기 — 공통 SDK v0.5.26 설치 및 전체 발급 회귀 검증

현재 프로젝트는 **무인민원발급기 Replit**입니다.

첨부한 `naebangsik-kiosk-accessibility-sdk-0.5.26.tgz`를 사용하여 현재 SDK v0.5.25를 **v0.5.26으로 업데이트**해 주세요.

패키지명은 `@naebangsik/kiosk-accessibility-sdk`입니다.

이번 작업은 SDK 업데이트와 기존 기능의 회귀 검증만 수행합니다.

**사용자가 요청하지 않은 새로운 기능, 디자인, 안내 문구, 동작 방식은 추가하거나 변경하지 마세요. 추가 작업이 필요하면 먼저 이유와 변경 범위를 보고하고 사용자 승인을 기다려 주세요.**

## 1. 작업 원칙

SDK-first 원칙을 유지합니다.

- 공통 SDK 문제는 데모커피 프로젝트의 SDK 원본에서 수정합니다.
- 무인민원발급기에서는 공식 SDK 설치 및 공개 API 연결 검증만 수행합니다.
- 호스트 전용 CSS 우회, 안내 패널 위치 하드코딩, SDK 내부 수정은 금지합니다.
- 기존 발급 업무와 안내 문구는 변경하지 않습니다.
- 중앙 QR 서비스와 운영 데이터는 변경하지 않습니다.
- Publish하지 않습니다.

공통 SDK 결함이 발견되면 무인민원발급기에서 임시 해결하지 말고 재현 조건을 보고한 뒤 해당 작업을 중단하세요.

## 2. SDK v0.5.26 설치

먼저 현재 SDK v0.5.25 설치 상태를 확인합니다.

그다음 첨부된 tarball을 설치하세요.

확인 사항:

- 설치 버전이 정확히 0.5.26인지 확인
- package.json과 package-lock.json 갱신
- 기존 v0.5.25 tarball 보존
- 새로운 tarball 파일 무결성 확인
- SDK 내부 소스 수정 없음
- TypeScript 검사 및 빌드 통과

기존 호스트 어댑터 `src/useKioskAccessibility.ts`는 변경이 필요하지 않다면 그대로 유지하세요.

## 3. 쉬운 말 안내의 자동 페이지 분할 검증

사용자는 다음 동작을 명시적으로 승인했습니다.

**긴 쉬운 말 설명은 SDK가 자동으로 여러 페이지로 나누고, 사용자는 이전·다음 버튼으로 읽습니다. 안내창 자체를 스크롤하지 않습니다.**

이번 SDK v0.5.26에서 구현된 동작입니다.

다음 사항을 검증하세요.

1. 짧은 설명은 정상적으로 한 페이지에 표시
2. 긴 설명은 실제 표시 가능한 높이에 따라 자동 분할
3. 분할된 설명의 원문 누락 없음
4. 설명의 순서 유지
5. 이전·다음 버튼으로 모든 페이지 이동 가능
6. 안내창 내부 휠·터치 스크롤 사용하지 않음
7. 본문 글씨 잘림 없음
8. 페이지를 넘겨도 안내창 상단 위치 유지
9. 접기·펼치기 정상
10. Smart Guide 시작·종료 후 이전 쉬운 말 페이지 복원

기존 실제 안내 문구가 짧아 자동 분할이 발생하지 않는다면, **브라우저 테스트에서만 임시 긴 설명 데이터를 사용**해 검증하세요.

테스트용 긴 문구를 실제 서비스 안내 데이터에 추가하지 마세요.

## 4. 상단 안내 패널 위치 안정성

이전 사용자 테스트에서 쉬운 말 안내의 이전·다음 버튼을 누를 때 패널이 상단 40% 공간 안에서 위아래로 이동했습니다.

v0.5.25부터 수정된 위치 안정성이 v0.5.26에서도 유지되는지 확인합니다.

우선 테스트 조건:

- 390×844
- 하단 조작 60%
- 매우 큰 글씨
- 큰 버튼
- 고대비
- 쉬운 말과 스마트 길잡이 활성화

검증할 동작:

1. 쉬운 말 첫 페이지 표시
2. 다음 페이지 이동
3. 이전 페이지 복귀
4. 여러 번 페이지 전환
5. 자동 분할 페이지 이동
6. 접기
7. 펼치기
8. 스마트 길잡이 시작
9. 스마트 길잡이 종료
10. 원래 쉬운 말 페이지 복원

각 상태에서 실제 패널의 `getBoundingClientRect().top`을 측정하세요.

기존 하단 조작 모드의 상단 기준인 약 8px를 유지하고, 동일 화면의 페이지·상태 전환으로 위치가 바뀌지 않아야 합니다.

일반 화면에서는 기존 상단 기준인 약 12px를 확인하세요.

## 5. 하단 스크롤 안내 회귀 검증

v0.5.24에서 안정화된 하단 스크롤 안내 동작을 유지합니다.

- 실제 업무 스크롤 영역 하단에서 12px 위에 표시
- 더 내려갈 내용이 있으면 반드시 표시
- 스크롤 중 위치 점프 없음
- 스크롤 끝에서는 숨김
- 다시 위로 스크롤하면 표시
- 쉬운 말·스마트 길잡이와 공존
- 버튼과 시각적으로 겹쳐도 안내를 숨기지 않음
- `pointer-events: none`으로 업무 클릭 방해 방지
- QR 모달에서는 활성 모달의 스크롤 상태 반영

**이전 문제가 재발하지 않도록 실제 Y 좌표를 측정하세요.**

특히 주민등록등본 유형, 주민등록번호 키패드, 증명서 표시 항목, 수수료 면제, 발급 부수 화면을 확인합니다.

하단 스크롤 안내를 주요 버튼과 겹치지 않도록 임의로 옮기거나 숨기지 마세요.

## 6. 스마트 길잡이 기능 회귀

기존 Development 체험 프로필 기준으로 확인합니다.

- Smart Guide 시작 전 대기: 10초
- slowGuidance 활성 시 표시: 15초
- 같은 단계의 키패드 입력 중 조기 종료 없음
- 표시 항목 선택 중 조기 종료 없음
- 부수 변경 중 조기 종료 없음
- 스크롤 중 조기 종료 없음
- 실제 업무 단계 변경 시 기존 안내 정리
- Smart Guide에 이전·다음 및 페이지 번호 없음
- Smart Guide 종료 후 쉬운 말 페이지와 접힘 상태 복원

실제 시작·종료 시간을 측정하세요.

다음 화면 크기를 검증합니다.

- 360×667

각 화면에서:

- 하단 조작 60%

를 확인하세요.

확인 사항:

- 안내 패널 위치
- 자동 페이지 분할
- 이전·다음
- 접기·펼치기
- 실제 버튼 높이 44px 유지
- 하단 스크롤 안내 위치
- 키패드 클릭
- 표시 항목 선택
- 부수 증감
- QR 도크
- 가로 넘침 여부
- 터치·휠 스크롤
- 브라우저 무응답 여부

실제 호스트 화면에서 확인하고, 자동 테스트만 통과한 것을 실제 기기 검증으로 표현하지 마세요.

## 10. 테스트 실패 시 대응

검증 중 문제가 발견되면 먼저 원인을 구분하세요.

### SDK 공통 문제

예:
- 자동 분할 페이지에서 텍스트 누락
- 상단 안내창 위치 점프
- 하단 스크롤 안내 위치 점프
- 안내 타이머 조기 종료
- 이전·다음 상태 오류

이 경우 무인민원발급기에서 SDK를 수정하지 않습니다.

재현 조건, DOM 상태, 좌표, 호출 순서와 오류 내용을 보고한 뒤 작업을 중단하세요.

### 기존 호스트 연결 문제

예:
- 실제 단계 전환에 잘못된 stepId 전달
- 스크롤 소유자 등록 누락
- 모달 상태 연결 오류

이 경우에도 이번 작업의 범위를 넘어서는 수정이라면 먼저 원인과 필요한 변경 사항을 보고하고 승인을 기다리세요.

**사용자 승인 없이 새로운 기능을 추가하거나 기존 동작을 변경하지 마세요.**
