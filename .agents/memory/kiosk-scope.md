---
name: Kiosk scope
description: Scope boundaries for the public-service kiosk demo and future integrations.
---

Keep the current project as a standalone Korean civil-document kiosk demo. Its present scope is the 주민등록표(등본) issuance simulation; QR, accessibility-profile, and AI interfaces are not part of this phase. The code may remain structured for later extension without exposing those concepts in the current UI.

**Why:** The user wants a realistic kiosk demo first and explicitly excluded integration-related UI from the current phase.

**How to apply:** Keep new work within the certificate kiosk unless the user explicitly expands the project scope.
